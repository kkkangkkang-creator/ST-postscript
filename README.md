# P.S. — 추신

실리태번 **일반 채팅 요청 끝에 사용자가 작성한 ASSISTANT → USER 두 턴을 추가**하는 독립 확장입니다.
확장 목록 표시 이름은 **추신 (프리필 강화)**입니다. SideStory나 Side-B 설치가 필요하지 않습니다.

## 설치

실리태번 → 확장 → 확장 설치에서 다음 주소를 입력하세요.

```text
https://github.com/kkkangkkang-creator/ST-postscript
```

설치 후 새로고침하고 **확장 설정 → P.S. — 추신**을 펼치세요.

1. ASSISTANT 칸에 예시 응답을 입력합니다.
2. USER 칸에 마지막으로 덧붙일 요청을 입력합니다.
3. **추신 사용**을 켭니다.
4. 평소처럼 채팅을 전송합니다.

두 칸과 토글은 자동 저장됩니다. 기본값은 OFF이며 기본 문구는 비어 있습니다. OFF여도 내용은 남습니다. 활성 상태에서 어느 한 칸을 비우면 OFF로 전환됩니다. 내용을 채운 뒤 다시 켜 주세요.

## 동작

```text
기존 프리셋·캐릭터·대화·이번 요청
ASSISTANT: 직접 작성한 예시 응답
USER: 마지막 요청
→ 실제 모델 응답 생성
```

ASSISTANT 내용은 사용자가 작성한 예시입니다. 모델을 한 번 더 호출하지 않습니다. 원본 채팅 기록은 수정하지 않으며, 설정을 바꾸면 다음 요청부터 적용됩니다. 저장 범위는 실리태번 사용자 계정의 전체 채팅 공통입니다.

`{{char}}`, `{{user}}` 등 실리태번 매크로는 전송 순간 현재 채팅 기준으로 치환합니다. 설정의 미리보기에는 작성한 원문을 표시하며, 마지막 적용 시각은 실제 전송 직전에 두 턴을 추가한 시각입니다. 요청 성공 여부를 나타내지는 않습니다.

## 적용 범위와 호환성

- 채팅 완성(Chat Completion) API 전용입니다. 이 API에서 선택하는 서비스에 적용됩니다. Text Completion에는 적용하지 않습니다.
- 일반 전송·재생성·스와이프에 적용됩니다. 일반 유형으로 실행되는 그룹 채팅/자동 생성에도 적용됩니다.
- quiet 요청(일반적인 요약·번역 및 다른 확장의 백그라운드 생성), 유저 사칭, 답변의 이어쓰기에는 적용하지 않습니다. 직접 새 일반 채팅 요청으로 실행하는 번역 명령 등은 일반 전송으로 처리됩니다.
- SideStory의 본편 연결 및 raw 요청은 quiet 유형이므로 이 확장에서 추가하지 않습니다. 다른 확장이 일반 채팅 유형으로 요청하면 적용될 수 있습니다.
- 도구 호출/도구 결과로 끝나는 요청은 호출 순서를 보존하기 위해 건너뜁니다.
- 기존 응답의 시작을 채우는 assistant prefill과 다른 기능입니다. 여기서는 완결된 두 메시지를 추가합니다. 서비스별 메시지 변환·실리태번 프리필·다른 확장의 후처리가 최종 전송 형태에 영향을 줄 수 있습니다.
- 추신은 컨텍스트 조립 후 추가되므로 입력 토큰이 늘어납니다. 이 확장이 기존 대화를 자동으로 자르지는 않습니다. 컨텍스트 한도를 가득 쓰는 경우 여유를 확보하세요.
- 모델의 응답이나 요청 수락을 보장하지 않습니다.

## 개발

런타임은 빌드·외부 라이브러리 없이 실행됩니다. 설정은 `extensionSettings.st_postscript`에 저장합니다. `CHAT_COMPLETION_SETTINGS_READY`의 요청 유형을 확인해 전송 직전에 메시지 배열 복사본에 추가합니다. 지원 이벤트가 없는 버전에서는 활성화를 막고 안내합니다.

```sh
npm install
npm test
```

개발 테스트에만 linkedom을 사용합니다. 순서·OFF·quiet 제외·중복 방지·매크로·도구 후속 요청·설정 UI·종료 정리 테스트 10개를 포함합니다. DOM과 전송 이벤트를 모의 실행해 검증했으며 실제 설치 환경의 화면 및 제공사 API 호출은 별도 확인이 필요합니다.
